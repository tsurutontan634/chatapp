## コンセプト

受講生(musashi)を聴衆ではなく**共著者**にする。

```
聴く(朝のゼミ・ポッドキャスト)
  → 喋る(課題に音声メモで回答 → #ai-thoughts)
  → 自分が教材になる(4回に1回の「回収回」)
  → エッセイになる(課題=影武者の取材質問。影武者が停滞草稿を代筆)
  → 耳で推敲(土曜の朗読回で自分のエッセイを聴く → 音声メモで殴る → v+1)
  → note公開(公開タップだけ本人)
```

- 教養(Season 1: 進化生物学)× 発信(停滞4本の打破)× 耳の時間(マラソン練習)× 実証済みの感想ループ、の一石N鳥。
- 「飲めない断定を3箇所仕込む」ことで、白紙には書けないが文句は言える性質を執筆エンジンに転用する。

## Season 1: 美意識の系譜(全12回)

発端は本人の明示リクエスト「『一途がかっこいい』の言い換えではなく、美意識の起源を生物学・進化レベルで掘ってほしい」。

1. ダーウィンとクジャクの尾 — 性淘汰という発見 (2026-08-19 配信済み)

3. 「一途」の進化 — ペアボンドと貞節のシグナリング
4. 回収回①
5. 対称性と平均性 — 「中庸」の生物学

7. 芸術は求愛ディスプレイか — ミラー『恋人選びの心』

10. 協力の美学 — 「必要とされたい」の進化
11. 美意識はどこまで生物でどこから文化か — 二重継承理論
12. 最終回収回 — musashiの美意識の系譜図
