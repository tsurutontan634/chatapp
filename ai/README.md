# AI提案システムの使い方

(あなた=リポジトリの持ち主向けの説明です。読むのはこのファイルだけでOK)

## これは何?

「自分で作るより、世の中にすでにあるものを探して組み合わせる」ためのしくみです。

AIがあなたのことを覚えたファイル(プロフィール)をもとに、既存のOSSやサービスをリサーチして、「こういうことできますよ」という提案を日常的に届けます。あなたが提案に反応するほど、AIの覚えているプロフィールが育ち、提案が賢くなっていきます(自己進化)。

## ファイルは3つだけ

| ファイル | 中身 |
|---|---|
| `ai/profile.md` | AIが覚えているあなたのこと(やりたいこと・好み・状況) |
| `ai/proposals/` | 提案レポート(日付ごとに1ファイル) |
| `ai/backlog.md` | 提案の一覧表。「気になる」「採用」「見送り」を記録 |

## ふだんの使い方(全部、日本語の会話だけでOK)

1. **提案を読む** … 毎朝の通知、または `ai/proposals/` の最新ファイル
2. **反応する** … Claudeに「3番気になる」「2番は今はいいや、理由は◯◯」と言うだけ。AIが一覧表とプロフィールを更新し、次からの提案が変わります
3. **作ってもらう** … 「3番やって」と言えば、既存のものを探して組み合わせる方針で実装します
4. **自分のことを話す** … 「最近◯◯に興味がある」と言えばプロフィールに追記されます

## 手動で提案がほしいとき

Claudeに「提案して」と言うか、`/teian` と入力してください。その場でリサーチして新しいレポートを作ります。

## 毎朝の自動提案(Routine)

毎朝7時(日本時間)に、AIが自動でリサーチして提案の要約を通知します。

- 頻度を変える・止める … Claudeに「毎朝の提案を週1にして」「毎朝の提案を止めて」と言うだけ
- この仕組みのブランチがリポジトリ本体に取り込まれる(マージされる)までは通知だけが届きます。取り込まれた後は、レポートが `ai/proposals/` にも自動で保存されるようになります
