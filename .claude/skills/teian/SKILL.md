# 提案スキル(/teian)

## 目的

車輪の再発明をせず、世の中にすでにあるものの中から「持ち主ができること」を見つけて提案する。提案への反応をプロフィールに還元し、次の提案を賢くする。

## 手順

1. `ai/profile.md`、`ai/backlog.md`、`ai/proposals/` の直近2ファイルを読む。
2. 引数や直前の会話に感想・返事(「3番気になる」「2番は見送り、理由は◯◯」など)があれば、先に `ai/backlog.md` の状態を更新する。好みが読み取れたら `ai/profile.md` の「提案の好み」にも反映する。
3. WebSearchで既存のOSS・サービス・事例をリサーチする(GitHub、Awesomeリスト、日本語の解説記事など)。
   - プロフィールの「興味」「好み」に合うものを優先する。
   - `ai/backlog.md` にすでにある提案は繰り返さない。
   - リンクは、検索結果で実在を確認できたものだけ書く。
4. 3〜5件を `ai/proposals/YYYY-MM-DD.md` に書く(同日2回目なら追記)。各提案の形式:
   - **タイトル**(何ができるようになるかを一言で)
   - **何ができる** / **なぜあなた向き**(プロフィールと結びつける)
   - **元ネタ**(実在するリンク)
   - **手間**: 小(その日のうち) / 中(数日) / 大(じっくり)
   - **頼み方**(そのままコピペで使える日本語一文)
5. `ai/backlog.md` に新提案を「未回答」で追記する。
6. 変更した `ai/` 配下のファイルをコミットし、現在のブランチにプッシュする。アプリ本体(`myapp/` など)のコードはこのスキルでは変更しない。
7. チャットに提案の要約(番号+タイトル+一言)を日本語で示し、「気になる番号を教えてください。『3番やって』で実装まで進めます」と締める。

## 書き方のトーン

- 専門用語はかみくだく。プログラマー向けの言い回しをしない。
- 「何ができるようになるか」を主役にする(技術名は元ネタ欄に添える)。
